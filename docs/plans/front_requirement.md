## 0. 前一轮前端错误复盘（三份 front 文档必读）

上一轮“前端迭代”只新增了 `#/graph` 图协议视图，并把首页的主叙事切到溯源图，
**错误地移除了旧功能入口**：

- 实验室列表、实验室创建（压缩包 / Git / 压缩包链接 / 空工作目录四种来源）从首页消失或不可达；
- 实验室启动 / 停止 / 删除 / 进入详情（含沙箱自动创建与执行）没有首页入口；
- 数字人、报告模板、MCP、Skills、设置等旧导航在不同视图下被隐藏；
- 结果是：图车道能看，但“建 lab → 自动起沙箱 → 跑任务”的既有闭环无法从首页开始。

**本轮红线**：不得再删除、隐藏或降级任何旧入口。新增图驱动模块必须与旧入口**并存**，
首页要同时能“演示图驱动范式”和“进入旧实验室闭环”。后端旧能力（多来源 lab 创建、
sandbox 自动初始化、agent/tool 执行、报告导出）保持原样，只做前端呈现。

## 1. 本轮目标

1. **全迭代组件有前端落点**：R1–R16 / Task 1–11 中每个用户可见能力，都能在 UI 找到对应展示或操作。
2. **首页切换到图驱动范式**：以“补丁 → 图 → 调度 → 沙箱证据 → 规则/完成”的顺序逐模块演示，
   不再以“总脑 + 研究组”作为首页主叙事。
3. **旧功能入口完整保留**：首页显式保留实验室列表、四种创建方式、启动/停止/删除、进入实验室。
4. **品牌更新**：标题与 slogan 按用户指定文案落地。
5. **可验收**：`npx tsc --noEmit`、`npm run build`、`go build`、真实页面截图四类证据齐全。

## 3. 首页信息架构（post-iteration）

自上而下：

1. **Top banner（顶栏）**
   - 标题：`ParchTrace | 寻迹 - Autonomous Penetration System`
   - slogan：`Trace the Patch, Uncover the Flaw.`
   - 右侧保留：刷新、数字人、报告模板、溯源图、MCP、Skills、设置。
2. **Hero / 图驱动总览**
   - 一句话：补丁是起点，溯源图是唯一知识与推理载体。
   - 车道状态徽标：`图 API 可用 / 不可用`、项目数、`active/completed/stopped` 统计。
   - 指标条：图项目、事实、意图、提示、证据边、完成项目。
3. **模块演示序列（逐模块展示，编号 01–07）**
   - 01 补丁摄入与反演（R7）
   - 02 溯源图事实 / 意图 / 提示（R3/R4/R12）
   - 03 推理与缺口（R8）
   - 04 Worker 调度与租约（R5/R6）
   - 05 沙箱实证与证据判决（R9/R10）
   - 06 规则回流与评测（R11/R14）
   - 07 完成、重开与导出（R10/R15）
   - 每个模块展示：实时指标或状态、对应 R 编号、进入“溯源图”的操作按钮。
4. **图项目速览**
   - 最近图项目列表：标题、状态、bootstrap、origin、reason worker；点击进入溯源图。
5. **实验室与沙箱（保留入口）**
   - 原实验室列表：启动 / 停止 / 删除 / 进入实验室。
   - 原创建实验室表单：四种来源（压缩包文件 / Git 仓库 / 压缩包链接 / 空工作目录）+ 总任务。
   - 文案需说明：该入口对应旧车道，与图车道并存；沙箱仍由后端自动创建与执行。
6. 旧导航页面（数字人、报告模板、MCP、Skills、设置）保持 hash 路由不变。
