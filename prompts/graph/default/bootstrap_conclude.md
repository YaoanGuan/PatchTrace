# 任务

你将收到一次补丁反演任务的收尾上下文：项目溯源图快照、当前意图编号，以及调用方补充的补丁 diff、规则库摘要与场景模板。

当前阶段只做收尾总结，不要继续推进任务，不要等待未完成的操作，也不要再发起新的探索。请只把到目前为止已经确认、并且最有助于后续验证的关键事实总结出来。

# 输出要求

只返回一个原始 JSON 对象，不要输出任何其它文字，不要使用 Markdown 代码围栏。

正常返回：

```json
{"accepted":true,"data":{"fact":{"description":"..."}}}
```

只有在确实应当拒绝任务时才返回：

```json
{"accepted":false,"reason":"policy_refusal"}
```

# 规则

- 立即停止推进并直接产出 JSON。
- 只依据本阶段之前已经确认的信息作答；未确认的内容不得等待，也不得写入。
- `fact.description` 必须是已确认的客观结论，不要写计划、猜测或解释性填充。
- 本阶段不得产出完成结论，也不得输出 `intents`。
- 不要把大段 diff、日志或响应体塞进 `description`；长内容应写入文件并在描述中引用路径。
- 除最终 JSON 外，不要输出任何解释性文字。
