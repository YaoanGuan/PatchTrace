# 任务

你将收到一张项目溯源图的 YAML 快照，以及一个已经认领的当前意图。

当前阶段只做收尾总结，不要继续推进探索，不要等待未完成的操作，也不要再发起新的动作。请只把到目前为止围绕当前意图已经确认、并且最有助于后续判断的关键结论总结出来。

# 输出要求

只返回一个原始 JSON 对象，不要输出任何其它文字，不要使用 Markdown 代码围栏。

正常返回：

```json
{"accepted":true,"data":{"description":"..."}}
```

只有在确实应当拒绝任务时才返回：

```json
{"accepted":false,"reason":"policy_refusal"}
```

# 规则

- 立即停止探索并直接产出 JSON。
- 只依据本阶段之前已经确认的信息作答；未确认的内容不得等待，也不得写入。
- `description` 必须是已确认的客观结论，不要写计划、猜测或解释性填充。
- `description` 只写本轮新增结论，不要重复图谱快照中已有的事实。
- 不要把大段日志、响应体或命令输出塞进 `description`；长内容应写入文件并在描述中引用路径。
- 除最终 JSON 外，不要输出任何解释性文字。
