# Langflow 场景模板（CVE-2025-3248）

## 目标组件
- 产品：Langflow
- 受影响版本：< 1.3.0
- 修复参考：PR #6911 / commit faac4db133de
- 漏洞类型：未认证远程代码执行（RCE），CVSS 9.3

## 端点形态
- 入口：`POST /api/v1/validate/code`
- 认证：无需登录（未认证可达）
- 参数位置：`body` 的 `code` 字段，内容为待校验的 Python 代码

## 反演要点
1. 修复 commit 在代码校验逻辑外层增加 sandbox/受限执行环境；修复前 `exec` 直接执行用户提交的 Python。
2. 触发条件：目标版本 < 1.3.0，且 `/api/v1/validate/code` 从攻击容器网络可达。
3. 受影响面：所有对外暴露该端点的 Langflow 实例；内网实例同样受影响。

## PoC 骨架
- 发送最小 JSON：`{"code": "<python expression>"}`
- 通过表达式返回值或副作用证明代码被执行，例如：
  - 返回算术表达式结果（验证表达式求值）
  - 写入临时文件后读取（验证副作用）
  - 仅在获得明确回显或副作用时判定成功

## 成功判定
- 响应中出现表达式计算结果或副作用证据 → 可利用。
- 仅返回参数校验错误、鉴权失败、WAF 拦截页或网络错误 → 不能判定成功，归为 error/inconclusive。

## 误报陷阱
- 端点存在但被反向代理限制访问，不等于漏洞不存在；需记录网络边界。
- 仅凭版本号匹配不足以判定；必须有实际执行证据。
- 修复后的 sandbox 可能仍允许部分表达式求值，不能把"能返回结果"直接等同于 RCE。
